# Supermarket Sales Dashboard

An Excel dashboard created to analyze supermarket sales data.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Data Visualization

## Dashboard Analysis
- Total Sales
- Revenue
- Average Rating
- Gross Income
- Sales Trend
- Revenue by City
- Payment Method Analysis
- Product Performance
